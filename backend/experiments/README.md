# experiments/ — script học tập, chạy độc lập
Nơi thử nghiệm nhỏ trước khi đưa vào kiến trúc chính, ví dụ:
- `step01_first_tool_call.py` — gọi Claude với 1 tool, in từng message (bước 1)
- `telegram_hello.py` — thử bot Telegram bằng long polling

Code ở đây không được import từ `app/`, và `app/` không import từ đây.
