# Playbook — bài học tái sử dụng cho dự án agent khác
> Viết dần trong quá trình làm, hoàn thiện ở **bước 20**.

## Checklist thiết kế agent (9 bước)
1. Bài toán & KPI — có thật sự cần agent?
2. Phân rã & topology
3. Thiết kế tool (trước prompt)
4. Threat model & policy
5. Eval trước prompt
6. Thiết kế context
7. Prototype → eval → lặp
8. Quan sát & vận hành
9. Pilot → rollout → cải tiến liên tục
