# 05 — Bảo mật & quản trị
> Viết ở **bước 10–11**. Hiện là khung — nội dung đầy đủ xem `PLAN.md`.

## Nội dung dự kiến
- Threat model: prompt injection (email, ảnh), lộ token, gửi nhầm mail, chi phí vượt
- Chính sách trong `config/policies.yaml`: mức rủi ro, quy tắc duyệt, giới hạn
- Quy trình duyệt, audit log, kill switch, lưu trữ dữ liệu (retention)
